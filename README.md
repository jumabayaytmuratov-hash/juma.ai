# Dars ishlanma — Netlify

Netlify'га бир марта жойланади. Кейин ҳамма ўзгаришлар админ панелдан қилинади, қайта жойлаш керак эмас.

## Жойлаш (бир марта)
1. Бу папкадаги файлларни GitHub'даги янги репозиторийга юкланг.
2. Netlify → Add new site → Import from Git → репозиторийни танланг (build созламаларини ўзгартирманг).
3. Site configuration → Environment variables: фақат иккитасини қўшинг:
   - `ADMIN_PASSWORD` — админ паролингиз (узун ва мураккаб)
   - `ADMIN_SECRET` — узун тасодифий матн (сессия имзоси)
4. Deploy. Сайт: `https://сайтингиз.netlify.app`, админ: `/admin.html`.

## Бепул сунъий интеллект
**Калитсиз ишлайди:** ҳеч нарса киритмасангиз ҳам, сайт бепул хизматлардан фойдаланади: аввал Pollinations, у ишламаса OVHcloud (иккаласи ҳам калит ва рўйхатдан ўтишни талаб қилмайди). Улар секинроқ (анонимларга дақиқасига бир неча сўров) ва сифати паст бўлиши мумкин. Синов ва кичик юклама учун мос. Жиддий ишлатиш учун пастдаги Gemini'га ўтинг.

Gemini'га ўтиш:
1. aistudio.google.com → Get API key (бепул, Google ҳисоби билан).
2. `/admin.html` → "AI sozlamalari": провайдер **Google Gemini**, калитни киритинг → Saqlash → "AI ishlayotganini tekshirish".
3. Модел номи бўш қолса, `gemini-flash-latest` ишлатилади. Google модел номини ўзгартирса, шу ердан алмаштирасиз.
Бошқа бепул вариантлар: Groq ёки OpenRouter ("OpenAI-mos" провайдер: манзил ва калитни киритинг).

## Админдан ўзгартириладиганлар
Нархлар (бир юклаш, йиллик Premium), бепул юклашлар сони, кунлик AI лимити, карта, Telegram манзили, AI калит ва модел,
дарс ишланма кўрсатмаси (prompt), кодлар яратиш ва ишлатилганини кўриш.

## Тўлов
Мижоз тўлайди → чекни Telegram'да юборади → сиз админда код яратиб берасиз → мижоз кодни киритади. Код фақат бир марта ишлайди.

## Эслатмалар
- Бепул Gemini чекловлари: дақиқасига ва кунига сўровлар сони чекланган. Лимитга тушса, AI хато қайтаради. Кунлик лимитни админда пасайтиринг.
- Google'нинг бепул тарифида киритилган матнлар Google томонидан маҳсулотни яхшилашда ишлатилиши мумкин ва тижорат ишлатилишига шартлар қўйилиши мумкин. Шартларни ai.google.dev/gemini-api/terms да текширинг. Керак бўлса, Google ҳисобида тўловни ёқинг: сўровлар жуда арзон.
- Лицензия қурилмага боғланган (браузер хотираси).
